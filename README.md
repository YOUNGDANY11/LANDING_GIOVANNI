# Vera FC · Póster Eduard Giovanni Morales Vera

Proyecto React + Vite + Tailwind CSS.

## Uso

```bash
npm install
npm run dev
```

Abre el enlace que muestra la terminal (por defecto http://localhost:5173).

## Build de producción

```bash
npm run build
npm run preview
```

## Estructura

- `src/App.jsx` — layout principal del póster
- `src/components/LicenseButton.jsx` — botón de licencia
- `src/components/TrainingAlert.jsx` — alerta lateral animada (desliza de derecha a izquierda, fondo translúcido)
- `src/data/licenses.js` — datos de licencias y contactos
- `src/assets/` — fotos (perfil y equipo)
